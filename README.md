# Gestor de Tareas



\## Estructura de index.html



El archivo `index.html` contiene la página principal del Gestor de Tareas.



\- `<h1>` muestra el título principal: Gestor de Tareas.

\- `<h2>` identifica la sección de tareas pendientes.

\- `<ul>` crea la lista de tareas.

\- `<li>` representa cada tarea pendiente.
